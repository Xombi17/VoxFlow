# Phase 2.1 Plan 04: Model catalogue Summary

Pinned local model catalogue with consented, SHA-256-verified, resumable downloads, a `voxflow models` CLI, SQLite selection, and a sherpa-onnx Parakeet provider behind `ASRProvider`. `make test` passes (150 tests, offline).

## Commits

- 1e3decb: manifest, settings store, list/select/remove (catalog.py also contains the download and build_provider code, so Task 2/3 logic landed in this commit)
- 1b8193f: models CLI and download tests
- 99e2916: Parakeet provider and factory tests

## Authoring-time hashes

Hashes came from real Hugging Face metadata (`lfs.oid` for LFS files; small non-LFS files downloaded once and hashed). URLs pin the repo revision SHA. No model weights were downloaded.

## Deviations from Plan

**1. [Rule 1 - Bug] Cross-host redirect rule vs real Hugging Face behaviour.** HF redirects model.bin to `us.aws.cdn.hf.co`, so a strict same-host rule would break every real download. Added manifest field `redirect_host_suffixes: ["hf.co"]`; any other host or non-https is refused, and the SHA-256 check still gates install. Files: catalog.json, catalog.py.

**2. [Packaging]** Added `package-data` for `catalog.json` to pyproject.toml.
