# Phase 2.1 Plan 03: Daemon, capture, and catalogue benchmark summary

Implemented the offline walking skeleton for the selected local catalogue model:
GlobalShortcuts activation starts one `AudioSession`, release closes capture,
`DictationJobRunner` transcribes the closed artifact, and `Inserter` receives the
raw transcript exactly once. Failed insertion retains the text and emits the
existing `copied — press Ctrl+V` hint. A missing or uninstalled selection gives
the explicit `voxflow models download ... && voxflow models use ...` command.

The sounddevice adapter opens the native input format lazily, downmixes and
linearly resamples callback chunks to 16 kHz mono PCM16 in memory, and reports a
typed `capture_stalled` failure after 500 ms without frames. The user service is
shipped but is not enabled by the project.

The benchmark now iterates installed catalogue entries without downloading,
computes word-level WER from a supplied reference sentence/file, writes the
existing `benchmark_results.json` row schema through catalogue helpers, and
selects the fastest non-reference model within two absolute WER points of the
best measured candidate and the 700 ms target. Reference text is represented
only by its SHA-256 in the CLI report.

The local Whisper runtime pins `av==18.1.0` alongside `faster-whisper==1.2.1`.
PyAV 19 removed the `metadata_errors` argument used by that faster-whisper
release, which otherwise surfaced as repeated `inference_failed` dictation
jobs even though the model was installed correctly.

The live portal smoke initially exposed two transport defects: dbus-next needs
list-backed D-Bus structs for `a(sa{sv})`, and the `Request::Response` match
must be installed before sending `CreateSession` or `BindShortcuts`. Both are
now covered by the transport implementation and the struct-shape regression
test. The live dbus-next signal callbacks also require exact arity, so the
adapter now wraps `Activated` and `Deactivated` with four-argument handlers.
