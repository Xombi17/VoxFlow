<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app -> RemoteDesktop portal | Grants keystroke injection into any focused app |
| transcript text -> clipboard | Dictated (possibly sensitive) text is placed on the system clipboard |
| state dir -> restore token | Token authorises re-granting input control without a dialog |
| ctypes -> libei | Native boundary receiving fds and keymap data from compositor |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-04 | Information Disclosure | restore_token.py | mitigate | 0600 file in 0700 dir, atomic write, reject wider-permission or symlink files, never log or print the token |
| T-02.1-05 | Elevation of Privilege | RemoteDesktop session | mitigate | SelectDevices types=KEYBOARD only (no pointer, no ScreenCast); session closed on daemon exit |
| T-02.1-06 | Information Disclosure | Clipboard | accept | Raw transcript remains on the clipboard in this phase (no restore, D-09); clipboard is not logged; revisit with sensitive-selection hint in Phase 4 (INSERT-03) |
| T-02.1-07 | Tampering | Wrong-target paste | mitigate | Inject only after trigger release, one chord, result never claims delivery (D-10) so user is told to verify |
| T-02.1-08 | Denial of Service | EIS/keymap parsing | mitigate | Bounded keymap read size, failure maps to `failed`/`unavailable`, no crash of daemon |
| T-02.1-09 | Information Disclosure | CLI output | mitigate | insert-test prints result code and hint only, not the text beyond what the user typed, never the token |
</threat_model>
