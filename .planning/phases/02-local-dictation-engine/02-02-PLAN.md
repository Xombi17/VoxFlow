<threat_model>
- **T2-03 malformed or misbound transcript:** a provider returns invalid segment/timing/language data or a result for another audio artifact. Mitigate with one Pydantic boundary validation and an exact SHA-256 match before success.
- **T2-05 model/network privacy failure:** startup or tests download weights or contact a service. Mitigate with read-only discovery, lazy imports, explicit installed model roots, network-deny tests, and no network code in the local provider.
- **T2-06 resource exhaustion:** repeated model loads or unbounded native inference harms the desktop. Mitigate with one bounded warm model per profile, explicit resource/time ceilings, cancellation tokens, and cold/warm/peak-resource measurements.
- **T2-09 metadata leakage:** benchmark output exposes transcript, samples, credentials, or machine paths. Mitigate with an allowlisted metrics schema and serialization tests that reject those fields.
</threat_model>
