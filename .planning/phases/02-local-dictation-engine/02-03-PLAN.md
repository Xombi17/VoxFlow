<threat_model>
- **T2-07 implicit network transmission:** local work silently falls back to a remote endpoint or a configured remote provider runs under local-only policy. Mitigate with an explicit provider selection plus `remote_explicit` network policy, pre-dispatch rejection, and zero-transport-call assertions.
- **T2-08 endpoint/credential exfiltration:** arbitrary schemes, embedded tokens, or raw provider errors leak sensitive configuration. Mitigate with HTTPS/approved LAN URL validation, environment-key references instead of persisted tokens, redacted errors, and safe probe output.
- **T2-03 remote result mismatch:** a remote response is accepted for the wrong input or with malformed timing metadata. Mitigate by reusing the shared `TranscriptResult` validator and exact artifact checksum check.
- **T2-09 remote metrics leakage:** request bodies or transcripts appear in metrics/logs. Mitigate with injected transport tests and the same allowlisted benchmark schema from 02-02.
</threat_model>
